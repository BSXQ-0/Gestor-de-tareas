# Gestor de Tareas

Una aplicación web para gestionar tareas construida con React y Tailwind CSS.

## 🚀 Demo en Vivo

Visita la aplicación: [https://BSXQ-0.github.io/Gestor-de-tareas](https://BSXQ-0.github.io/Gestor-de-tareas)

## 📦 Estructura del Proyecto

- `frontend/gestor-tareas-app/` - Aplicación React
- `backend/` - API Backend

## 🛠️ Desarrollo Local

### Frontend

```bash
cd frontend/gestor-tareas-app
npm install
npm start
```

La aplicación estará disponible en [http://localhost:3000](http://localhost:3000)

## 📝 Despliegue

La aplicación se despliega automáticamente a GitHub Pages cuando se hace push a la rama `main`.

Para desplegar manualmente:

```bash
cd frontend/gestor-tareas-app
npm run deploy
```

## 🧪 Tecnologías

- React 19.2.0
- React Router 6.30.2
- Tailwind CSS
- Axios para peticiones HTTP
